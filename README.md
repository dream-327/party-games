# 🎮 聚会游戏盒子 (Party Games Hub)

专为聚会、团建、宿舍开黑打造的**多人实时联机聚会游戏合集平台**！
只需一台电脑启动，支持**局域网（WiFi/手机热点）扫码秒玩**与 **Cloudflare Tunnel 异地公网穿透联机**。所有玩家无需下载任何 APP，手机或电脑浏览器打开链接即可畅玩！

## 🌟 当前已集成游戏

### 1. 🕵️‍♂️ 《谁是卧底》(Who is Undercover)
- **游戏人数**：4 ~ 12 人
- **核心特色**：
  - **3D 防窥抽卡翻牌**：支持手机手指长按翻开、离开即隐藏，防止邻座偷看底牌。
  - **丰富分类词库**：包含经典对决、生活日常、搞笑扎心、影视动漫、吃货天下等 100+ 精选词组，并支持房主自定义词组。
  - **智能完整流程**：洗牌发言倒计时、平票 PK 辩论、淘汰震撼音效、结算公开复盘与败者真心话/大冒险趣味抽卡。
  - **健壮网络设计**：房主离线自动王冠继承、离线玩家防死锁跳过。

### 2. 🃏 《欢乐斗地主》(Fight the Landlord)
- **游戏人数**：3 人（支持真实好友联机 + 智能 AI 电脑补位）
- **核心特色**：
  - **全套经典斗地主规则**：54 张牌洗牌发牌、3 张神秘底牌、叫地主/抢地主倍数翻倍。
  - **全牌型智能识别**：单张、对子、顺子、连对、飞机带翅膀、四带二、炸弹与王炸（火箭）。
  - **春天与反春倍数**：农民未出牌（春天）或地主仅出一手牌（反春）自动触发双倍并伴随专属音效。
  - **智能 AI 陪练与代打**：不足 3 人时房主可一键添加 AI 机器人补位；真实玩家可随时开启「托管」，离线时自动代打防挂机。
  - **纯 Web Audio 原生音效**：发牌刷牌、出牌落地、叫牌、炸弹爆破、王炸升空、春天号角、胜败音乐全由浏览器实时合成，零网络延迟！

### 3. 🐺 《聚会狼人杀》(Party Werewolf)
- **游戏人数**：3 ~ 10 人（支持真实好友 + 智能 AI 电脑补位）
- **核心特色**：
  - **🌙 一夜终极模式 (One Night Werewolf)**：
    - **无提前淘汰**：所有人全程参与，无需坐冷板凳。
    - **神反转身份对调**：强盗偷换新身份、捣蛋鬼调换他人身份、醉鬼盲换底牌、失眠者末尾查牌、制皮匠一心求死！

  - **🐺 经典多夜模式 (Classic Werewolf)**：
    - 支持预言家、女巫（解药/毒药）、猎人、守卫、村民与多恶狼多轮天黑天亮、放逐辩论！
  - **3D 防偷窥查牌**：支持手指按住/触摸翻开查看底牌，松手即刻翻回隐藏。
  - **沉浸式音效**：狼嚎声、公鸡破晓啼鸣、处决洪钟全由浏览器纯原生实时合成。

## 🚀 快速启动指南

### 方式一：一键启动服务器与公网穿透（推荐）
双击运行根目录下的 [`start_all.bat`](start_all.bat)：
1. 自动启动 Node.js 本地游戏服务器（端口 3000）。
2. 自动启动 Cloudflare 穿透隧道并生成临时公网安全域名（形如 `https://xxxx.trycloudflare.com`）。
3. 异地朋友无论身在何处，直接打开该公网链接或扫码即可一起开黑！

### 方式二：仅启动本地/局域网服务器
双击运行 [`start_server.bat`](start_server.bat) 或在终端中执行：
```bash
cd D:\aiWork\party-games
node server.js
```
终端会打印当前电脑的局域网 IP（例如 `http://192.168.1.100:3000`），同 WiFi / 手机热点下的朋友打开即可。

├── start_all.bat          # 一键启动服务与公网穿透

│   │   ├── server.js

## 🛠️ 技术栈
- **后端**：Node.js、Express、Socket.IO (Namespaces 命名空间隔离)
- **前端**：原生 HTML5、CSS3 (Flexbox/Grid/Animations)、JavaScript (ES6+)
- **音效引擎**：HTML5 Web Audio API 原生振荡器与滤波合成
- **穿透方案**：Cloudflare Tunnel (`cloudflared`)
