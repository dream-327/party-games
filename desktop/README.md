# 🎮 聚会游戏盒子 - 电脑桌面客户端 (Windows)

专为《聚会游戏盒子》打造的轻量级 Windows 电脑桌面客户端。

## 🌟 核心特色

1. **🚀 极速分发（仅 22KB）**：无需朋友电脑安装 Node.js、Python 或任何运行环境，通过微信、QQ 秒发给朋友即可双击打开。
2. **🖥️ 独立应用视窗**：无浏览器地址栏、无多余标签页，拥有独立的任务栏图标与原生应用视窗，支持按 `F11` 键一键全屏（非常适合客厅大屏/投影投屏）。
3. **☕ 云端服务冷启动唤醒感知**：针对 Render 免费实例休眠特性，内置连接检测面板，友好提示唤醒状态，避免网页白屏。
4. **🔒 独立数据存储**：与日常浏览器缓存严格隔离，玩家头像、昵称、房间记录安全持久化在本地。
5. **🔄 多服务器自由切换**：默认自动连接公网服务器 `https://party-games-b3bm.onrender.com`，同时支持输入局域网 IP（如 `http://192.168.1.4:3000`）进行本地开黑。

---

## 📦 如何发送给朋友

您可以直接把以下任一文件直接发送给好友：
- **方案 A（单文件）**：直接发送 `聚会游戏盒子.exe` 给好友，双击即可进入游戏。
- **方案 B（压缩包）**：将包含 `聚会游戏盒子.exe` 与 `app.ico` 的压缩包发送给好友。

本项目使用 Windows 系统内置的 C# 编译器（无需安装任何外部开发工具）：
