# 聚会游戏盒子·《间谍危机》（Spyfall）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在聚会游戏盒子（`party-games`）中新增《间谍危机》（Spyfall）独立游戏模块，包含特征重叠混淆题库算法、服务端全双工状态机与数据脱敏流、移动端特工暗黑防窥界面以及新手玩法指导体系。

**Architecture:** 采用“服务端权威状态机 + 客户端每人独立脱敏”模型。服务端统一托管倒计时绝对时钟与暂停恢复，按特征簇动态注入兄弟地点生成 16~18 个候选池；前端采用 Mobile-first 纯原生架构，集成长按显现防窥卡牌、本地交互式排查板、新手指南弹窗与 Web Audio 原生合成音效。

**Tech Stack:** Node.js, Express, Socket.IO, Vanilla JavaScript (ES6+), HTML5/CSS3 (Flexbox/Grid), Web Audio API, Screen Wake Lock API.

**Spec:** [docs/superpowers/specs/2026-09-22-spyfall-design.md](file:///D:/01_%E9%A1%B9%E7%9B%AE%E5%B7%A5%E7%A8%8B/party-games/docs/superpowers/specs/2026-09-22-spyfall-design.md)

## Global Constraints

- 零外部运行时新依赖：仅使用 `package.json` 中已有的 `express`, `socket.io`, `socket.io-client`，前端使用纯原生技术栈。
- 绝对数据脱敏：在 `GAME_OVER` 之前，任何客户端数据包不得泄露未公开的真实地点（对间谍脱敏）和其他玩家的真实角色分配。
- 统一字母/字典序：下发给所有玩家（包括平民和间谍）的候选地点列表必须保持绝对相同的排布顺序。
- 移动端防窥：看牌操作必须为单指长按（Hold-to-Reveal），松手或页面发生滚动即刻复原为遮盖状态。
- 纯手动与防频繁打扰：每位玩家每局仅能发起一次指控；指控需全票赞成方可生效。

### Task 1: 地点簇题库与近邻混淆池生成算法

**Files:**
- Create: `games/spyfall/locations.js`
- Test: `test_spyfall_locations.js`

**Interfaces:**
- Produces:
  - `CLUSTERS`: Array of cluster definitions with id, name, description.
  - `LOCATIONS`: Array of 24~30 location objects `{ id, name, icon, clusterId, roles, fallbackRole }`.
  - `UNIVERSAL_ROLES`: Array of common roles present across multiple venues (`['安保人员', '保洁员', '维修工', '访客/顾客']`).
  - `getRandomLocation()`: Returns a random location object.
  - `generateCandidateLocations(targetLocationId)`: Generates 16~18 locations containing the target, all brother locations in the same cluster, 2~3 weakly related locations, and padding locations, sorted canonically.

- [ ] **Step 1: Write the failing unit test for location clusters and pool generation**

```javascript
// test_spyfall_locations.js
const assert = require('assert');
const {
  CLUSTERS,
  LOCATIONS,
  getRandomLocation,
  generateCandidateLocations
} = require('./games/spyfall/locations');

console.log('🧪 开始测试地点簇与混淆候选池算法...');

// 1. 题库完整性测试
assert(Array.isArray(CLUSTERS) && CLUSTERS.length >= 6, '必须包含至少 6 个核心特征簇');
assert(Array.isArray(LOCATIONS) && LOCATIONS.length >= 24, '必须预置至少 24 个高品质地点');

LOCATIONS.forEach(loc => {
  assert(loc.id && loc.name && loc.icon && loc.clusterId, `地点 ${loc.id} 缺少必填字段`);
  assert(Array.isArray(loc.roles) && loc.roles.length >= 5, `地点 ${loc.name} 角色数必须 >= 5`);
  assert(loc.fallbackRole, `地点 ${loc.name} 必须配置兜底角色`);
});

// 2. 随机抽取与近邻混淆池算法测试
const randomLoc = getRandomLocation();
assert(randomLoc && randomLoc.id, '应当成功随机抽取一个真实地点');

const candidates = generateCandidateLocations(randomLoc.id);
assert(candidates.length >= 16 && candidates.length <= 18, `候选池数量必须在 16~18 之间，实际: ${candidates.length}`);

// 3. 强关联兄弟地点注入断言
const brothersInCluster = LOCATIONS.filter(l => l.clusterId === randomLoc.clusterId);
brothersInCluster.forEach(brother => {
  const found = candidates.some(c => c.id === brother.id);
  assert(found, `特征簇兄弟地点 [${brother.name}] 必须被强制注入候选池中以保障迷惑性`);
});

// 4. 排序一致性断言 (按拼音/字符升序排列)
for (let i = 0; i < candidates.length - 1; i++) {
  const comp = candidates[i].name.localeCompare(candidates[i + 1].name, 'zh-CN');
  assert(comp <= 0, `候选池地点必须保持字典序一致排列: ${candidates[i].name} vs ${candidates[i+1].name}`);
}

console.log('✅ 地点簇与混淆候选池算法测试全部通过！');
```

```javascript
// test_spyfall_server.js
const assert = require('assert');
const { PHASES, getSafePlayerView, createGameRoom, startGameForRoom, handleAccuse, handleSpyGuess } = require('./games/spyfall/server');

console.log('🧪 开始测试服务端状态机与数据脱敏...');

// 1. 初始化房间
const room = createGameRoom('1001', { id: 'p1', name: '房主张三', avatar: '🤠' });
assert.strictEqual(room.gameState.phase, PHASES.LOBBY);
assert.strictEqual(room.players.size, 1);

// 2. 加入平民与测试数据
room.players.set('p2', { id: 'p2', name: '李四', avatar: '🦊', isOnline: true });
room.players.set('p3', { id: 'p3', name: '王五', avatar: '🤖', isOnline: true });
room.players.set('p4', { id: 'p4', name: '赵六', avatar: '🐼', isOnline: true });

// 3. 开始游戏
startGameForRoom(room, { durationMinutes: 8 });
assert.strictEqual(room.gameState.phase, PHASES.PLAYING);
assert(room.spyId, '必须随机指定一名间谍');
assert(room.targetLocation, '必须指定真实地点');
assert(room.candidateLocations.length >= 16, '必须生成候选池');

// 4. 间谍视角脱敏断言
const spyView = getSafePlayerView(room, room.spyId);
assert.strictEqual(spyView.self.isSpy, true);
assert.strictEqual(spyView.self.location, null, '间谍端真实地点必须为 null');
assert.strictEqual(spyView.self.role, '间谍 (Spy)');

// 5. 平民视角脱敏断言
const civilianId = Array.from(room.players.keys()).find(id => id !== room.spyId);
const civView = getSafePlayerView(room, civilianId);
assert.strictEqual(civView.self.isSpy, false);
assert.strictEqual(civView.self.location, room.targetLocation.name, '平民必须看到真实地点');
assert.notStrictEqual(civView.self.role, '间谍 (Spy)');

// 6. 他人信息绝密断言 (游戏进行中不可窥探他人角色)
civView.players.forEach(p => {
  assert.strictEqual(p.role, '???', '未结束时他人身份必须为 ???');
  assert.strictEqual(p.isSpy, undefined, '未结束时不得泄露谁是间谍');
});

// 7. 指控与投票流转断言 (暂停倒计时)
assert.strictEqual(room.gameState.isPaused, false);
const accuseResult = handleAccuse(room, civilianId, room.spyId);
assert(accuseResult.success, '发起指控应成功');
assert.strictEqual(room.gameState.phase, PHASES.PAUSED_ACCUSE);
assert.strictEqual(room.gameState.isPaused, true, '发起指控时倒计时必须暂停');

console.log('✅ 服务端状态机与数据脱敏测试全部通过！');
```
